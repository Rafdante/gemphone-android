# GemPhone 3.9 — быстрый ИИ-агент для Android (Termux + Accessibility Bridge + Фон)

Мультипровайдерный ИИ-агент, живущий прямо в **Termux** на Android и управляющий смартфоном
через локальный **AccessibilityService Bridge** (без ADB и Wi-Fi), ADB (резерв), Vision и Termux:API.

## Что нового в 3.9
- **Ускорение управления в 3–5×**:
  - HTTP/1.1 Keep-Alive между Python и Kotlin Bridge + постоянный пул соединений к LLM API.
  - Быстрые JPEG-скриншоты прямо на Android (`/screenshot?max_dim=1280&quality=82`) без тяжелого PNG.
  - Пакетный эндпоинт `POST /batch` и инструмент **`phone_batch`** — серия тапов/ввода + свежий UI-дамп за один шаг.
  - Исправлен JSON-контракт `/status` и `/ui`, подключён Bridge `/app` (`list`, `launch`, `open_url`), убраны утечки `AccessibilityNodeInfo`.
- **Автономная работа в фоне** (`gemphone-bg` + `gemphone_daemon.py`, без Telegram):
  - Держит `termux-wake-lock`, обрабатывает локальную очередь `~/.gemphone/queue/` за `<0.25с`.
  - Запуск задач из консоли (`gemphone-bg ask "..."`), голосом (`gemphone-bg voice`), с рабочего стола через **Termux:Widget** (`gemphone-bg widget`) и автозапуск через **Termux:Boot** (`gemphone-bg boot`).
  - Оповещения в шторку Android + вибрация при завершении задачи.
- **Единая безопасность (`safety.py`)**:
  - Защита `run_command`, SSRF-фильтр в `web_fetch`, запрет не-`http(s)` ссылок в `open_url`, приватные файлы `0600` (`write_private`), блокировка `dangerous`-операций в фоновом режиме по умолчанию.

## Установка из архива

```bash
unzip -o gemphone-android-v3.9-fast.zip -d ~
mv ~/gemphone-android-main ~/gemphone-android   # если распаковали в новую папку
cd ~/gemphone-android
bash install.sh
```

## Сборка обновлённого APK `GemPhone Bridge`
Залейте обновлённую папку `bridge/` в свой GitHub-репозиторий и запустите workflow
**Actions → Build GemPhone Bridge APK**, затем установите `app-debug.apk`.
В приложении **GemPhone Bridge** нажмите:
1. `0. Android 13+: Разрешить огр. настройки`
2. `1. Фон без ограничений` (отключите оптимизацию батареи для Bridge и Termux)
3. `2. Включить в Спец. возможностях`
4. `3. Скопировать команду для GemPhone` и вставьте `/bridge token ...` в `gemphone`.

## Сопряжение и приватность

Тестовые APK из Actions подписываются временным отладочным ключом сборки.
Старый опубликованный ключ скомпрометирован. При несовместимости подписи потребуется
удалить прежний Bridge (его локальные настройки будут потеряны), установить новый
APK из доверенной сборки и повторно включить службу и выполнить сопряжение.
Для стабильных обновлений нужен отдельный защищённый ключ релиза.

Новая версия меняет токен Bridge. Скопируйте команду сопряжения кнопкой в Bridge
и вставьте её в GemPhone в Termux. Старые копии токена в «Загрузках» утрачивают силу
для новой версии. Их можно удалить вручную. Токен в буфере обмена после сопряжения
можно заменить обычным текстом. Новые команды хранятся в истории только до выхода.

Для инструментов чтения экрана, SMS, контактов, уведомлений, буфера обмена,
местоположения и сведений Wi-Fi требуется разовое согласие перед передачей
результата модели. В фоне такие запросы отклоняются, в том числе для пакетных
действий с чтением экрана. Полученные ранее данные могут сохраняться в истории
диалога у выбранного провайдера.

## Фоновый режим

```bash
gemphone-bg start                       # запустить фоновый демон + wake-lock
gemphone-bg status                      # статус демона и Bridge :7331
gemphone-bg ask "открой настройки Wi-Fi"
gemphone-bg ask --wait "!status"        # отправить и дождаться ответа
gemphone-bg voice                       # диктовка голосом (Termux:API)
gemphone-bg widget                      # ярлык на рабочий стол (Termux:Widget)
gemphone-bg boot                        # автозапуск после перезагрузки (Termux:Boot)
gemphone-bg stop                        # остановить
```
